# HunyForge — Project Context

- **What it is:** Local AI-assisted 3D asset generation and Unity export preparation.
- **Audience:** Unity developers with capable NVIDIA GPUs.
- **Differentiator:** Private local generation with staged low-VRAM inference and explicit Unity validation.
- **Stage:** Pre-development planning.
- **Next goal:** Complete E01, then validate shape and staged texture generation on the target PC.

## Constraints

- RTX 4080 16 GB VRAM and 32 GB system RAM baseline.
- Unity export preparation is mandatory.
- No cloud inference or v1 telemetry.
- Preserve provenance and never overwrite artifacts.
- Keep `STATUS.md` honest about implemented, verified, unverified, and blocked work.
